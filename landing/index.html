Why this matters

Prove it. Don't paraphrase it.

Answers are cheap; provenance is what costs you. For compliance, audit, legal, scientific, or contract work — being wrong has consequences. You don't want a summary. You want one you can verify in the actual document.

Snippets are excerpts of the real text and pixels. Every claim links to a page coordinate or quoted passage, re-openable in the source. The document stays the source of truth.

What it is

The anchor layer for documents.

Seven things Marklee gives you that a notes app or PDF reader doesn't.

Portable annotations

Plain JSON sidecars next to the source. Email someone paper.pdf + paper.pdf.annot.json — they get your annotations, fully.

Edit-tolerant anchoring

A normative four-tier algorithm finds your highlight even after the source has been edited: text + context → exact → fuzzy in section → orphaned.

Lineage graph

Connect snippets with labeled edges — supports, contradicts, elaborates. The graph is first-class data. MarkRank surfaces the most-cited ideas.

Permalinks

Share a snippet as a URL — hash + anchor + optional text. The receiver opens the source and lands on the region. Text Fragments, for documents.

Cross-format

One snippet schema across PDF, Markdown, DOCX, and plain text. Lineage view mixes them on one canvas.

Bundled figure detector

An Apache-2.0 RT-DETR ONNX model ships with the app — figure/table boxes resolve in Rust on CPU. No Python, no API key, no cloud.

Open spec

Every detail in SPEC.md + a JSON Schema for CI validation. The format is the contract; tools are interchangeable.

How it works

Highlight, anchor, share.

Three views from inside Marklee.

① Capture by selection or drop

Drag-select text in any document. Drop a sticker to tag it. Paste text or images directly into the workspace.

② See your reading as a graph

The lineage view shows snippets as a directed labeled graph — docs, snippets, and groups in three columns. Edges encode your reasoning; MarkRank ranks by centrality.

③ Share a single annotation as a URL

Click share on any snippet. The Permalink encodes hash + page + anchor; the receiver opens the source and lands on the region — even if the source has been edited.

The format

JSON, next to the source. That's it.

One sidecar per document. Every snippet, edge, and group lives inside. Self-describing, version-controllable, scriptable. 

{
  "markleeVersion": "0.1",
  "kind":           "document",
  "source": {
    "path":        "genome.pdf",
    "kind":        "pdf",
    "contentHash": "sha256:ab12cd34…"
  },
  "snippets": [
    {
      "id":            "3f7e…",
      "page":          12,
      "text":          "Humans share roughly 98.8% of their DNA with chimpanzees.",
      "contextBefore": "…comparative genomics has revealed that ",
      "contextAfter":  " The remaining 1.2% accounts for…",
      "anchor":        "Chapter 3 > Common ancestors",
      "comment":       "Worth re-checking against the 2023 update.",
      "groups":        ["evidence", "biology"]
    }
  ],
  "edges": [
    {
      "source": "3f7e…",
      "target": "a9b2…",
      "label":  "supports"
    }
  ],
  "groups": [
    {
      "id":   "evidence",
      "name": "Evidence"
    }
  ]
}
Where it shines

Five reading workflows that get easier.

Built for annotations that live with the file, survive edits, and link to each other.

Literature review

Quotes from a dozen PDFs into one workspace, dragged into themed folders — methods, limitations, open questions. MarkRank surfaces the most-cited ideas.

Contract review

Anchor concerns to clauses with quoted text + context. When the counterparty edits around them, comments still resolve — the four-tier algorithm finds them.

Research synthesis

Connect a quote in paper A to a counter-claim in paper B with a labeled edge — supports, contradicts, elaborates. Your argument as a graph, not a list.

Mixed-format research

PDF, Markdown, DOCX, and plain text in one workspace — same snippet schema everywhere. Cross-format lineage just works.

Shareable citations

Right-click any highlight → copy share link. URL encodes the document hash + anchor. No server, no account, no expiry.

How it compares

Different layer of the stack.

  • ObsidianVault vs. source. Obsidian holds notes you wrote; Marklee marks the source someone else wrote.
  • HypothesisServer vs. file. A JSON sidecar next to the document — no account, no cloud round-trip.
  • Web ClippersCopy vs. anchor. Clippers stash text in a vault; Marklee re-resolves against the live source.
  • Document AIExtraction vs. curation. Marklee ships a bundled RT-DETR detector — but the product is what humans marked, not what a parser found.
  • Adobe / PreviewEmbedded vs. sidecar. Source stays byte-identical; annotations travel as a sibling JSON.
